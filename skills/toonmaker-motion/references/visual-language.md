# Visual Language: Modern UI Motion with Cartoon Character Accents

## Design objective

Make an explainer that feels like a polished modern interface brought to life. The interface-like graphic system is the subject's visual vocabulary. Cartoon influence comes from color, shape, outline, icon personality, and occasional expressive illustration, not from turning the entire video into a character animation.

## Visual priority order

1. Core information: diagrams, comparisons, data, sequences, labels, and key terms.
2. UI structures: cards, panels, windows, tabs, chips, toggles, meters, progress indicators, and modular surfaces.
3. Graphic accents: icons, stickers, arrows, abstract shapes, lines, particles, and small decorative marks.
4. Character accents: small illustrated guides, reaction figures, or mascots used sparingly.

A character should never obscure the main information or occupy most of the frame without a clear communication purpose.

## UI-inspired components

Create a consistent component library where useful:

- `Panel`: main container or information region.
- `Card`: one concept, fact, or comparison item.
- `Chip`: short category, tag, or state.
- `Metric`: number with a label and optional change indicator.
- `Progress`: steps, completion, or relative quantity.
- `Callout`: short explanation attached to a visual item.
- `Timeline`: ordered events or stages.
- `DiagramNode`: labeled node in a flow or relationship map.
- `IconBadge`: simple pictogram inside a compact shape.
- `CharacterAccent`: an illustrated figure with a defined supporting role.

Do not show a fake product interface and imply that it is a real app or source. These are visual metaphors unless the video is specifically explaining an actual interface.

## Composition rules

- Establish a clear primary focal point in every scene.
- Use a grid and consistent alignment; vary scale and arrangement for rhythm.
- Keep safe margins for captions and platform overlays.
- Do not put dense paragraphs inside tiny cards.
- Use a chart only when its encoding is clear and data is available.
- Show relationships spatially: sequence, grouping, contrast, hierarchy, or cause and effect.
- Leave breathing room around key words and important diagrams.

## Cartoon-inspired styling

Use a restrained set of visual traits, such as rounded corners, bold but controlled outlines, slightly exaggerated icon shapes, friendly color accents, hand-drawn flourishes, soft shadows, or simple vector characters. Avoid stacking every trait at once. The goal is polished and modern, not preschool clip art.

## Character usage

Characters are optional. Use them as:

- A small presenter in an opening or closing corner.
- A reaction beside a surprising result.
- A pointer or guide directing attention to a panel.
- A scale reference or brief human-context illustration.

Keep character design simple and reusable. A character should generally appear for only the beats in which it adds meaning. Do not write character dialogue as the default narration format. The narrator explains; the character supports the visual explanation.

Avoid:

- Full-screen character acting sequences.
- Continuous lip-sync or dialogue scenes unless explicitly requested.
- Elaborate cinematic locations or film-like camera staging.
- Complex character rigs that consume time without improving understanding.
- Character-led story arcs that displace the educational message.

## Typography

Use a clear display face for short headlines and a highly legible sans-serif for explanatory labels. Use no more than two font families unless the user requests a specific brand identity. Maintain a readable hierarchy and strong contrast. Avoid decorative fonts for long text, numbers, or captions.

## Color

Choose a compact palette with clear semantic roles. Check text contrast against each background. Do not rely on color alone to communicate status or category; add labels, icons, patterns, or shape differences when useful.

## Motion personality

Use confident, clean movement:

- Short, controlled easing for card and panel entrances.
- Staggered reveals for grouped information.
- Directional transitions that preserve spatial continuity.
- Small overshoot only for playful emphasis, not every movement.
- Progress fills and line draws to communicate a process.
- Scale or focus changes to emphasize a single item.

Avoid constant bobbing, random particle storms, excessive bounce, and transitions that compete with narration.
